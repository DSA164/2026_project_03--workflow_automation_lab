# Use Case — BD Kids Hunter

## Functional goal

Detect interesting listings for children’s comic book lots in Belgium.

## Target criteria

- Around 1 € per comic book
- Prefer lots over single items
- French or Dutch
- Good condition
- Belgium
- Reasonable shipping costs

## Why this is pedagogically useful

This use case is simple enough to understand, but rich enough to teach:

- parsing;
- normalization;
- scoring;
- uncertainty;
- deduplication;
- alerting;
- later, local AI enrichment.
